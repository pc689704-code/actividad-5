# actividad-5


¿Qué es Recuva y para qué se utiliza? 
 RTA=Recuva es un programa utilizado para recuperar archivos que han sido eliminados accidentalmente. Puede recuperar documentos, imágenes, videos y otros tipos de archivos desde discos duros, memorias USB, tarjetas SD y otros dispositivos.


¿En qué sistemas operativos puede funcionar Recuva? 
 RTA=Recuva funciona principalmente en sistemas operativos Windows.



¿Cuál es la importancia de elegir la ubicación correcta para el escaneo en Recuva? 
 RTA=Elegir la ubicación correcta permite que Recuva busque los archivos eliminados en el lugar donde probablemente se encontraban. Esto hace que el proceso de búsqueda sea más rápido y eficiente.




¿Qué significa el indicador de color verde al lado de un archivo en Recuva? 
 RTA=El color verde indica que el archivo está en buenas condiciones y que existe una alta probabilidad de recuperarlo correctamente.






¿Qué diferencia hay entre un escaneo normal y un escaneo profundo en Recuva? 
 RTA=El escaneo normal es más rápido y busca archivos eliminados utilizando la información disponible en el sistema de archivos. El escaneo profundo realiza una búsqueda más exhaustiva y puede encontrar archivos que el escaneo normal no encuentra, aunque tarda más tiempo.




¿Por qué es recomendable guardar los archivos recuperados en una unidad diferente a la que se
escaneó? 
 RTA=Porque guardar los archivos recuperados en la misma unidad puede sobrescribir los datos eliminados que todavía podrían recuperarse. Utilizar otra unidad ayuda a evitar esta pérdida de información.



Enumera tres tipos de archivos que se pueden recuperar con Recuva. 
 RTA=
Documentos, como DOCX y PDF.
Imágenes, como JPG y PNG.
Videos, como MP4 y AVI.



¿Qué limitación común tiene Recuva al recuperar archivos en cuanto a la estructura de carpetas? 
 RTA=Al recuperar archivos, Recuva puede no conservar la estructura original de carpetas y subcarpetas, especialmente cuando se utiliza el escaneo profundo.




¿Qué indica un archivo marcado con un círculo rojo en los resultados de Recuva? 
 RTA=El círculo rojo indica que el archivo está en muy malas condiciones o ha sido sobrescrito, por lo que las posibilidades de recuperarlo correctamente son muy bajas.




¿Cuál es la recomendación principal para aumentar las chances de recuperación exitosa con
Recuva después de borrar un archivo?v
RTA=La recomendación principal es dejar de utilizar la unidad inmediatamente después de borrar el archivo, para evitar que nuevos datos sobrescriban el espacio donde se encontraba y dificulten su recuperación
